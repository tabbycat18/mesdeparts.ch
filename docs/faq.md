# FAQ

## What is mesdeparts.ch?

mesdeparts.ch is a Swiss public-transport departures project with a focus on a clear, realtime departure-board experience.

## What does this repository contain?

This repo is the public landing page and documentation home for the project.

## Is mesdeparts.ch open source?

Some parts of the project are public. The legacy client is open source, but the current production stack is not public.

## What is not included here?

This repo keeps proprietary backend, deployment, operational, debug, and private config details out of public view.

## What is the legacy repo?

The legacy repo contains the open-source legacy client: https://github.com/tabbycat18/mesdeparts.ch-legacy

## Is the live service the same as this public repo?

The live service is the public face of mesdeparts.ch. This repo documents the project, but it does not contain the full private production system.

## Can I contribute?

Public-facing improvements are welcome if they fit this repo or the legacy client.

## How do I report a bug or security issue?

For non-security feedback, use the public issue tracker when the topic belongs in this repo. For security issues, follow [SECURITY.md](../SECURITY.md) and report privately.

## Can I self-host this?

This repo is documentation-only. For the legacy client and self-hostable public code, start with the legacy repo.

## Where should I start reading next?

Start with [docs/README.md](README.md), then [architecture.md](architecture.md), [SECURITY.md](../SECURITY.md), and the legacy repo if you want the open-source client.
